# Références locales de Centurion

Les sources et les extraits utilisés pour construire le modèle sont décrits dans le [catalogue public des références](../simulateur/references.html), dans [`METHODE-CENTURION.md`](../simulateur/METHODE-CENTURION.md) et dans le chapitre **Modèle** de l'application. Les identifiants REF-01 à REF-08 sont neutres ; la correspondance avec les documents originaux est conservée localement dans `inventaires/references-locales.json`.

Le dossier de travail local peut contenir :

- `sources/` : PDF, ouvrages et extraits documentaires ;
- `inventaires/` : inventaires Excel des éléments graphiques ;
- `reference/` : copies des premières versions du simulateur ;
- `versions-originales/` : synoptiques avant adaptation.

Ces fichiers de support sont conservés localement et ne sont pas distribués avec le dépôt. Les liens de l’application ouvrent le catalogue public plutôt que des documents privés. Les originaux ne sont pas modifiés ; des copies aux noms neutres permettent leur consultation locale. Le simulateur et ses tests fonctionnent sans ces documents.
