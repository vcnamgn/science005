# Références locales de Centurion

Les sources bibliographiques et les extraits utilisés pour construire le modèle sont décrits dans [`simulateur/METHODE-CENTURION.md`](../simulateur/METHODE-CENTURION.md) et dans le chapitre **Modèle** de l'application.

Le dossier de travail local peut contenir :

- `sources/` : PDF, ouvrages et extraits documentaires ;
- `inventaires/` : inventaires Excel des éléments graphiques ;
- `reference/` : copies des premières versions du simulateur ;
- `versions-originales/` : synoptiques avant adaptation.

Ces fichiers de support sont conservés localement et ne sont pas distribués avec le dépôt. Certains liens documentaires de l'application pointent vers `support/sources/` ; ils fonctionnent si l'utilisateur dispose de ces références et les ajoute à cet emplacement. Le simulateur lui-même fonctionne sans ces documents.
